# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Angular SSR (zoneless) + Tailwind 4, бэкенд FastAPI + PostgreSQL 16, Docker Compose + nginx, деплой на VPS (Oracle Cloud Always Free ARM). Стек задан шаблоном проекта.

## Users

Путешественники, которые перед поездкой выбирают eSIM для мобильного интернета за границей. Два рынка: русскоязычный и англоязычный, две языковые версии. Приходят из поиска по запросам вида «eSIM для Турции» / «eSIM for Japan». Задача: быстро понять, сколько трафика нужно, какой тариф взять и как подключить.

## Product Purpose

Справочник eSIM по странам с калькулятором трафика под конкретную поездку. Страница страны отвечает на вопросы: какие есть тарифы, сколько ГБ хватит на N дней, как подключить, работает ли на моём телефоне. Цель: органический трафик из поиска и переходы по партнёрским ссылкам. Успех измеряется поисковым трафиком и кликами на партнёров; конкретные цифры пока не заданы.

## Positioning

Калькулятор трафика под поездку: считает ГБ по числу дней и сценариям использования (карты, мессенджеры, видео) и подсказывает подходящий тариф. Справочники с голыми списками тарифов так не делают.

## Operating Context

Контент по странам собирается из одного набора данных (seed-файл в бэкенде), страницы генерируются по шаблону. Шаблон проекта служит конвейером для серии сайтов, поэтому структура должна масштабироваться на десятки стран без ручной вёрстки.

## Capabilities and Constraints

- Монетизация: партнёрские ссылки на провайдеров eSIM.
- Данные о тарифах вносятся в seed-файл со страниц провайдеров, старт с 10-15 стран и небольшого набора тарифов. У каждой цены указывается дата обновления.
- Две языковые версии (ru, en), отдельные URL для SEO.
- Публичный адрес из `PUBLIC_URL`, `robots.txt` и sitemap отдаёт бэкенд.
- API версионируется: `/api/v1`.
- Не решено: название бренда и домен (рабочее имя репозитория `esim-compass`), список стран и провайдеров, партнёрские программы.

## Brand Commitments

Нет. Рабочее имя `esim-compass`, не утверждено. Из вкуса владельца: без эмодзи (включая флаги), без «ИИ-слопа» (индиго-фиолетовые градиенты, одинаковые скруглённые карточки, значки в кружках).

## Evidence on Hand

Нет реальных данных о трафике, отзывов, кейсов, цен провайдеров. Ничего из этого нельзя выдумывать: ни отзывы, ни рейтинги, ни цены, ни количество пользователей. Тарифы появятся только после ручного ввода реальных данных.

## Product Principles

1. Честные данные: у каждой цены дата и источник, ничего придуманного.
2. Ответ на странице страны виден сразу, без ухода в блог и без регистрации.
3. Калькулятор главнее списка тарифов: сначала понять потребность, потом выбрать.
4. Одна структура страницы на все страны, чтобы серия сайтов масштабировалась шаблоном.
5. Партнёрские ссылки помечены, рекомендация не зависит от размера комиссии.

## Accessibility & Inclusion

Стандарт WCAG 2.2 AA, мобильная вёрстка в первую очередь (читают с телефона в поездке), две языковые версии.
